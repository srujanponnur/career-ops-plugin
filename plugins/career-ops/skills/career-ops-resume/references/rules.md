# Resume rules
- One page, US Letter, Calibri, 10 pt body (9.5 minimum), 0.5" side margins.
- Every bullet: action + what was built + measurable result, bold only the 2–4 terms a recruiter scans for.
- Numbers must be the candidate's confirmed numbers. Watch for category errors (funding vs business impact; team work vs own work).
- Public names only: never put an employer's internal code names on a resume.
- Variant differences are ordering, selection and summary — not different facts.
- Keep dates identical across variants and to the profile.
- Match each target JD's exact keywords where they're true (ATS filtering is keyword-based).
- No photos, no tables, no text boxes, no columns — they break ATS parsers.
